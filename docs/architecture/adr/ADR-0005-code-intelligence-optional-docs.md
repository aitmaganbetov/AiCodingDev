# ADR-0005: Обязательный локальный индекс кода; документация OFF/SMART/STRICT; без обязательной векторной БД

- **Статус:** Accepted (ТЗ §12, §22)
- **Дата:** 2026-11-07

## Решение
1. Индекс кода обязателен и привязан к `(repository_id, commit_sha, index_version)`: file tree, символы (tree-sitter), ripgrep для точного поиска, PostgreSQL FTS (`tsvector`) + `pg_trgm` для нечёткого, граф зависимостей (imports/calls/tests), связи тестов, инкрементальное хэширование файлов (sha256 содержимого → переиспользование чанков).
2. LSP — опционально по языкам, доступным в окружении (начальный набор — OQ-09).
3. **Context Pack** = детерминированно собранный пакет (manifest + фрагменты) с бюджетом размера; ключ кэша `sha256(commit + policy_version + task inputs)`; устаревший фрагмент (commit ≠ base task commit) блокируется или маркируется `stale: true`.
4. Порядок поиска: deterministic search → symbol/graph → optional docs → compact Context Pack → CLI → incremental reindex.
5. Documentation mode: `OFF` (внешняя документация не загружается), `SMART` (default: локальный код/кэш, загрузка нового источника — только через approval `DOCS_DOWNLOAD`), `STRICT` (для заданных проверок нужны утверждённые источники, иначе `BLOCKED`/`MANUAL_REVIEW`).
6. pgvector/embeddings — P2, выключены, не требуются ни одним сценарием v1.0.

## Последствия
+ Работа полностью офлайн в режиме OFF (AC-10).
− Качество ранжирования без эмбеддингов ограничено; измеряется метрикой полезности (доля фрагментов, на которые сослались подтверждённые результаты), без обещаний экономии.

## Связанные требования
FR-CI-*, FR-DOC-*, AC-02, AC-10.
