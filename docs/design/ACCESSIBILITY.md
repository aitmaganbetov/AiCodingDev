# Доступность AiCodingDev Web (WCAG 2.2 AA)

Цель — **WCAG 2.2 уровня AA** (решение D-1, `UI_REDESIGN_PLAN.md` §5.9). Документ фиксирует метод проверки
и результаты фазы F9 (2026-11-09). Код и тесты — `apps/web`; правила для разработчиков — `apps/web/README.md`.

## Исправлено по визуальному аудиту

- 768–1279 px: название workspace заходило под поле поиска (переключатель не сжимался) — переключатель сжимается, меню пользователя компактное (< 1280 px).
- Code Review без diff: пустое состояние было смещено вправо пустой колонкой дерева файлов — колонка не резервируется.
- Настройки на 375 px: активный подраздел обрезался в горизонтально прокручиваемой навигации — навигация переносится по строкам.
- Высота каждой страницы была на 1 px больше окна (граница верхней панели) — лишняя вертикальная прокрутка убрана.

## Известные исключения и ограничения

- **Ручная проверка скринридерами (NVDA, VoiceOver), zoom 200 % и reflow 320 px** в среде F9 не выполнялась (нет ОС/скринридеров в контейнере); покрыто только автоматикой (axe, роли/имена в тестах Testing Library и Playwright). Рекомендуется перед выпуском.
- **Широкие таблицы данных** (установки GitHub, аудит, исполнения CLI) на 375 px прокручиваются горизонтально внутри своего контейнера — исключение 1.4.10 для двумерных таблиц; страница целиком не прокручивается.
- **Редактор Monaco** (Code Review, side-by-side diff) — сторонняя разметка; не входит в проверку 2.5.8; альтернатива — текстовый вид diff с комментариями под строками.
- **Панорама графов** (DAG, граф зависимостей) — перетаскивание фона; без перетаскивания: кнопки масштаба/«вписать» и полный доступный список узлов и связей.
- **2.4.13 Focus Appearance** — уровень AAA, не требуется для AA; соблюдается как ориентир.
- Правило axe `target-size` для цели, частично закрытой sticky верхней панелью при текущей прокрутке, перепроверяется после прокрутки к цели — это положение прокрутки, а не размер цели.

## Как повторить

```bash
cd apps/web
pnpm test                                    # tokens, cvd, PageHeading и остальные unit
AICD_E2E_PORT=4199 pnpm e2e                  # все mocked-спеки (axe WCAG 2.2, wcag22.spec.ts)
AICD_E2E_PERF=1 AICD_E2E_PORT=4199 pnpm exec playwright test -c playwright.mocked.config.ts e2e/mocked/wcag22.spec.ts -g performance
AICD_E2E_AUDIT_DIR=/tmp/audit AICD_E2E_PORT=4199 pnpm exec playwright test -c playwright.mocked.config.ts e2e/mocked/wcag22.spec.ts -g "screen audit"
pnpm build && pnpm size                      # бюджет начального JS 260 kB gzip
```
